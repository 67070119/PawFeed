# PawFeed — Social Impact

PawFeed มุ่งเพิ่มการประสานงานของคนในพื้นที่ในการดูแลสัตว์จรจัด โดยทำให้ตำแหน่ง รูป เวลาที่ให้อาหารล่าสุด และการยืนยันการพบเห็นอยู่ในระบบเดียว

ผลเชิงบวกที่คาดหวัง:
- ลดการเดินทางซ้ำไปยังจุดที่เพิ่งมีคนให้อาหารแล้ว
- ช่วยให้จุดที่ยังไม่ได้รับการดูแลมองเห็นได้ง่ายขึ้น
- ทำให้ข้อมูลจากอาสาสมัครหลายคนต่อเนื่องกว่าการบอกต่อในแชท
- ช่วยนำทางไปยังพิกัดจริงเมื่อผู้ใช้ตัดสินใจเข้าไปช่วยเหลือ

ข้อควรระวัง:
- ข้อมูลเป็น community-generated และอาจคลาดเคลื่อน
- ไม่เปิดเผยตำแหน่งผู้ใช้เป็นข้อมูลสาธารณะ; geolocation ใช้ฝั่ง browser เพื่อช่วยเลือก/ดูตำแหน่งเท่านั้น
- `NOT_FOUND` หนึ่งครั้งไม่ทำให้ระบบปิดจุดอัตโนมัติ เพื่อลดความเสี่ยงจากรายงานผิดพลาด
