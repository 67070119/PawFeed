# PawFeed — Target Users

## Primary Users

- คนในชุมชนหรือมหาวิทยาลัยที่พบสัตว์จรจัดและต้องการแจ้งตำแหน่ง
- คนที่ให้อาหารสัตว์จรจัดและต้องการดูว่าจุดใดเพิ่งได้รับอาหารแล้ว
- อาสาสมัครที่ต้องการเปิดแผนที่ ดูรายละเอียด และเดินทางไปยังจุดจริง

## Main Jobs To Be Done

1. เห็นจุดสัตว์จรจัดใกล้พื้นที่ที่สนใจ
2. รู้ข้อมูลพื้นฐาน รูป และสถานะล่าสุดของจุด
3. เพิ่มจุดใหม่ด้วยตำแหน่งจริง
4. บันทึกการให้อาหารเพื่อให้คนอื่นเห็นข้อมูลล่าสุด
5. ช่วยยืนยันว่าจุดยังมีสัตว์อยู่หรือไม่

## Non-target Users in MVP

ระบบรุ่นนี้ไม่ได้ออกแบบเป็นระบบบริหาร shelter, โรงพยาบาลสัตว์, ระบบรับเลี้ยง หรือระบบติดตามสัตว์เลี้ยงส่วนบุคคล
