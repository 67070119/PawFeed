# AI Tool Usage

PawFeed อนุญาตให้ทีมใช้ AI Coding Tools ช่วยในกระบวนการพัฒนา เช่น วิเคราะห์ Requirement, ออกแบบระบบ, ตรวจสอบโค้ด, เขียน Test และช่วยจัดทำเอกสาร

## Current Usage

- ChatGPT: ใช้ช่วยวิเคราะห์ Requirement ของ Mini Project, วางโครงสร้าง Repository, วาง Development Phase และช่วยตรวจความสอดคล้องกับเอกสารของรายวิชา
- AI/LLM ไม่ได้เป็น Runtime Feature ของ PawFeed MVP

## Team Responsibility

ทีมยังคงรับผิดชอบต่อ:

- ความถูกต้องของโค้ดและเอกสาร
- Security และ Privacy
- License ของ Dependency และ Source ที่นำมาใช้
- Defect และ Known Limitation
- การอธิบาย Data Flow, Architecture และส่วนที่สมาชิกแต่ละคนรับผิดชอบ
- การตรวจสอบโค้ดหรือข้อเสนอจาก AI ก่อนนำเข้าสู่ระบบจริง

เอกสารนี้ต้องอัปเดตเมื่อมีการใช้ AI Tool เพิ่มเติมหรือเปลี่ยนรูปแบบการใช้งานอย่างมีนัยสำคัญ
