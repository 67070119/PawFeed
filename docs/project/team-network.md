# PawFeed — Team & Network

## Team Responsibilities

งานถูกแบ่งตามความรับผิดชอบที่ตรวจได้ใน repository:

- Product/Requirement: ดูแล Problem, Scope, Acceptance Criteria และ Traceability
- Frontend: Next.js, Map, Auth UI, Point/Feeding/Profile flow
- Backend: Express API, Prisma, PostgreSQL, Upload, Security/Validation
- DevOps/QA: Docker Compose, Jenkinsfile, Unit/Integration/E2E, Course Container verification
- Documentation/Demo: Evidence, Report, Slide และ Video flow

## Team Member Names

รายชื่อสมาชิกจริงและหน้าที่รายบุคคลต้องกรอกตามทีมที่ลงทะเบียนก่อนส่งงาน ห้ามใช้ชื่อสมมติในเอกสารส่ง

## External Network

PawFeed พึ่งบริการภายนอกเฉพาะส่วนที่เหมาะสมกับ MVP:
- OpenStreetMap tiles สำหรับแผนที่
- Google Maps URL สำหรับ Navigation ภายนอก
- GitHub สำหรับ Source Control
- Docker Hub/Microsoft Container Registry/npm registry สำหรับ dependency และ test/runtime images

ระบบหลักและข้อมูลธุรกรรมไม่ได้พึ่ง AI service ภายนอก
