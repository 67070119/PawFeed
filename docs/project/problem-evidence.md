# PawFeed — Problem & Evidence

## Problem

ชุมชนมักไม่มีข้อมูลกลางที่บอกว่าสัตว์จรจัดอยู่ตรงไหน พบล่าสุดเมื่อไร และมีคนให้อาหารไปแล้วหรือยัง ทำให้การช่วยเหลือซ้ำซ้อน บางจุดถูกละเลย และข้อมูลจากการบอกต่อกระจัดกระจาย

## PawFeed Response

PawFeed รวมตำแหน่งสัตว์จรจัดบนแผนที่เดียว ให้สมาชิกสร้างจุดพร้อมรูป บันทึกการให้อาหาร ยืนยันว่า `STILL_HERE` หรือ `NOT_FOUND` และเปิด Navigation ไปยังพิกัดจริงได้

## Evidence Strategy

Mini Project จะพิสูจน์ปัญหาและ solution ผ่านระบบ End-to-End จริง ไม่ใช้ mock ใน Critical Flow โดยหลักฐานเชิงระบบอยู่ใน `docs/evidence/` และ Traceability Matrix

## Scope Boundary

PawFeed MVP ไม่อ้างว่าแก้ปัญหาสัตว์จรจัดทั้งหมด ไม่ทำระบบรับเลี้ยง ไม่ทำระบบสัตวแพทย์ และไม่ auto-delete/auto-inactive จุดจากรายงานเดียว ข้อมูลชุมชนจึงยังต้องใช้วิจารณญาณของผู้ใช้
